# PriceCentric - Range Pricing Application

PriceCentric is a Java-based range pricing application designed to craft tailored product solutions for specific markets and channels. By enabling seamless creation and management of market solutions that combine products from different manufacturers, PriceCentric establishes a direct connection between customers and marketing agents. The platform empowers administrators to monitor sales against target prices and provides comprehensive sales analytics reports to deliver strategic insights into revenues and address key business questions.

---

## Project Overview

Businesses often face challenges in setting optimal prices for product bundles across diverse markets and channels. PriceCentric addresses this by allowing users to:
- Combine products from multiple manufacturers into market-specific solutions.
- Track and analyze sales performance against predefined target prices.
- Generate actionable analytics for revenue optimization and business strategy.

---

## Core Features

- **Market Solution Creation:**  
  Combine products from different manufacturers to create customized solutions for specific markets and channels.

- **Customer-Agent Connection:**  
  Facilitate direct interaction between customers and marketing agents for tailored product offerings.

- **Sales Monitoring:**  
  Administrators can monitor sales performance in real time, comparing actual sales to target prices.

- **Comprehensive Sales Analytics:**  
  Generate detailed reports with insights into revenue, sales trends, and key business metrics.

- **Strategic Decision Support:**  
  Address critical business questions such as:
  - Which product combinations drive the highest revenue?
  - How do actual sales compare to targets in different regions?
  - What are the most successful channels and market solutions?

## Getting Started

### Prerequisites

- Java JDK 8 or above
- A Java IDE (e.g., Eclipse, NetBeans, IntelliJ IDEA)

### Setup Instructions

1. **Clone the Repository**
    ```
    git clone https://github.com/MaliniSankaran/PriceCentric.git
    cd PriceCentric
    ```

2. **Open the Project**
    - Import the project into your Java IDE.

3. **Build and Run the Application**
    - Locate the main class (`RangePricingApplication.java`).
    - Build and run the application.
    - Follow on-screen instructions to create market solutions, add products, and generate reports.
